# Book Shop — интернет-магазин книг

Лабораторная работа по веб-программированию.

**Сайт:** https://ltael.github.io/book-shop/

## Возможности
- Каталог из 12 книг классической и современной прозы с обложками и ценами
- Окно «Подробнее» с описанием книги
- Добавление книг в корзину, изменение количества, удаление
- Автоматический пересчёт итоговой суммы
- Корзина сохраняется в localStorage и не пропадает после обновления страницы
- Форма оформления заказа (имя, фамилия, адрес, телефон) с проверкой полей
- Сообщение «Заказ создан!» после оформления
- Адаптивная вёрстка для ноутбука, планшета и телефона

## Технологии
HTML, CSS, JavaScript без фреймворков.

## Структура
- `index.html` — разметка страницы
- `style.css` — стили и медиазапросы
- `script.js` — логика каталога, корзины и формы заказа
- `images/` — обложки книг
